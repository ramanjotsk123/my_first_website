
# Kalra's Tutorials
### Official Educational Website

A responsive educational website developed independently for my own coaching institute, Kalra's Tutorials, based in Ujjain, Madhya Pradesh, India.

## 🌐 Live Website

[Visit Kalra's Tutorials](https://ramanjotsk123.github.io/my_first_website/)

## 📖 About the Project

Kalra's Tutorials is an educational website designed to establish a professional online presence for my coaching institute. It provides students and parents with information about the institute, academic programmes and student achievements.

## 🚀 Features

- Professional educational website design
- Institute information and academic details
- Student achievements and results section
- Student photographs and media
- Responsive layout for desktop and mobile devices
- Simple and user-friendly navigation

## 🛠️ Technologies Used

- **HTML5** – Website structure and content
- **CSS3** – Styling, layout and responsive design
- **GitHub Pages** – Website hosting and deployment
